# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-31

### Added
- First public release of Deskbird!
- Electron-based transparent, click-through desktop overlay bird companion.
- Smooth spring-damper cursor following with edge flipping and hovering drift.
- Wooden perch widget at top-right of primary screen with landing and takeoff states.
- 8-bit retro speech bubble with character-by-character typewriter and delivery status.
- Zero-config first run with deterministic secret generation and base32 Room ID derivation.
- Resilient Socket.IO message relay server on Render with offline queues (24h TTL) and rate limiting.
- Mobile-friendly static web sender app hosted on Vercel with real-time delivery ticks.
- Full sprite art suite defined in pixel matrices and exported to PNG spritesheets.
- Comprehensive local testing harness (`npm run dev:all`, `npm run demo`, `npm run test:install`).
